# Shireesha — AI Friend

Ready-to-deploy mobile-first Vercel project.

## Setup
1. Import this project/repository into Vercel.
2. In Vercel Project Settings → Environment Variables add:
   `GROQ_API_KEY` = your Groq secret key.
3. Optional: add `GROQ_MODEL` = `openai/gpt-oss-20b`.
4. Deploy and open the generated Vercel URL.

Never put API keys in frontend code or commit them to GitHub.
